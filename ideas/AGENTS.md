# ideas/AGENTS.md

This directory is only for pending ideas.

Rules:
- Create one short `ideas/<slug>.md` file per idea.
- Keep each idea note actionable and tightly scoped.
- If an idea is implemented, tested, and verified, delete its `ideas/<slug>.md` file in that same task.
- Do not leave completed ideas in this directory. A file that still exists in `ideas/` is treated as backlog, not done.
